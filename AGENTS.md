# Codex Çalışma Kuralları

- Her görev öncesinde mevcut dosyaları incele.
- İlgisiz dosyalarda değişiklik yapma.
- Server Components kullanımını varsayılan kabul et.
- Client Component yalnızca etkileşim gerektiğinde kullan.
- `dangerouslySetInnerHTML` kullanma.
- Gerçek kişisel veri ekleme.
- API anahtarı veya gizli bilgi ekleme.
- Gereksiz bağımlılık kurma.
- Değişikliklerden sonra `npm run lint` ve `npm run build` çalıştır.
- Yapılmayan testleri yapılmış gibi belirtme.
