# İkizler Yapı

## Proje Hakkında

İkizler Yapı, hayalî bir inşaat ve mimarlık firması için geliştirilen kurumsal web sitesi portföy projesidir.

“İkizler Yapı, portföy amacıyla oluşturulmuş hayalî bir markadır. Bu proje herhangi bir gerçek şirketi, web sitesini veya marka kimliğini kopyalamaz ve herhangi bir gerçek kuruluşla bağlantılı değildir.”

## Kullanılan Teknolojiler

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- ESLint
- npm

## Yerel Kurulum

Node.js 20.9 veya daha güncel bir sürümün kurulu olduğundan emin olun. Ardından:

```powershell
npm install
npm run dev
```

Uygulamayı `http://localhost:3000` adresinde açın.

## Geliştirme Komutları

```powershell
npm run dev
npm run lint
npm run build
npm run start
```

## Proje Durumu

Proje başlangıç kurulumu aşamasındadır. Nihai sayfa tasarımı ve içerik bölümleri henüz geliştirilmemiştir.

## Lisans ve Marka Uyarısı

Projenin açık kaynak lisansı henüz belirlenmemiştir. “İkizler Yapı” adı ve bu projedeki içerikler yalnızca portföy sunumu için kullanılan hayalî unsurlardır.
